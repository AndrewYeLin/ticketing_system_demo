What can Finance help with?

Start by selecting a request type and sub-type.

* Required fields

Expense lines

Enter either Total Excl. GST or Total Incl. GST for every line. The request total uses Total Incl. GST when supplied; otherwise it uses Total Excl. GST.

Category * Total Excl. GST ($) Total Incl. GST ($) Description Receipt *
Calculated from all expense lines. If a line has both amounts, its Total Incl. GST is used; otherwise its Total Excl. GST is used.

Supporting documents

Required files appear under Required documents; optional extras can be added under Other documents. Files are uploaded securely when the request is saved or submitted. Maximum 10 MB per file.
