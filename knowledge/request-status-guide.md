# Synthetic Request Status and Workflow Guide

> **Academic demo only.** Status names describe this COMP6708 prototype and are **not** official PolyU workflow commitments.

## Common status ideas

The tracker can show states such as:

- Draft
- Submitted
- Returned for Info
- Updated and Resubmitted
- In Progress
- Completed

Some request types have additional specialised stages.

## Returned requests

When a request is returned for information, the user should review the request, provide the missing demo information or documents, and resubmit it.

## Status questions

For a request ID such as `FR-20261005-001`, the assistant may read the actual status from the demo tracker. It should distinguish live tracker data from synthetic policy guidance.

## Timing

A status indicates workflow state only. The prototype does not guarantee real-world processing times or payment dates.
