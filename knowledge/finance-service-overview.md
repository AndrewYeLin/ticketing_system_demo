# Synthetic Finance Service Overview

> **Academic demo only.** This is synthetic course material for COMP6708 and is **not** an official PolyU policy, procedure, or service commitment.

## What the demo service covers

The Finance Request Tracker accepts demo requests in these categories:

- Procurement
- Reimbursement
- Travel Allowance
- Supplier Setup for Finance-admin demonstrations

The conversational assistant may explain the demo workflow, help users identify which request type fits a scenario, and retrieve request status from the tracker.

## General process

A user prepares a request, supplies the required demo information and supporting documents, submits it, and then follows its status. Finance staff may return a request when information is missing. A returned request can be updated and resubmitted.

## Important boundary

The assistant must not present these synthetic rules as real university policy. Real operational questions must be checked against the relevant official university source outside this prototype.
